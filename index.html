Pokémon Numerals

What if numbers were Pokémon?

Numeral system

Definition

In Pokémon Numerals, an integer n is represented by the Pokémon whose National Pokédex number is n.

Zero is represented by MissingNo., which Pokémon Red and Blue list as No. 000.

Integers greater than 1025 are written positionally in base 1026, with MissingNo. as the zero digit. Negative integers are written upside down.

The base increases with each new generation. Backwards compatibility is not guaranteed.

Practical applications have not been observed.

An unofficial fan project, not affiliated with Nintendo, Creatures, GAME FREAK or The Pokémon Company. Names and sprites come from PokéAPI.
